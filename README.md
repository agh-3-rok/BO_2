## Rozmieszczenie routerów wifi np. w B1 ;p

# Wprowadzenie:
Interesuje nas znalezienia optymalnego rozwiązania rozłożenia przestrzennego sieci routerów wifi, w celu uzyskania jak najlepszych parametrów, jak najmniejszym kosztem.

## Założenia:

- skończona liczba stacji
- określona fizyka - nieliniowy rozkład zasięgu 
- określona geometria przestrzeni - np. ściany
- można łatwiej 2D - trudniej 3D - badać piętra
- można skwantować przestrzeń
- można się zastanawiać jakie routery będą najlepsze do danego zagadnienia (zasięg, cena, etc.)... (wydaje się bardzo trudne -> wielokryterialne)

## Cele:
- jak najlepszy zasięg w najważniejszych miejscach - funkcja celu i kary
- ile najlepiej routerów dać żeby możliwie tanio ogarnąć? (złożone, wielokryterialne)
